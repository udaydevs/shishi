# 🛍️ Shishi E-commerce Platform

A robust, full-featured e-commerce solution built with Python/Django. It features dedicated user and admin portals, secure authentication, and an architecture ready for scalable deployment.

## ✨ Key Features

Based on the visible file structure (`adminPortal`, `ecom`, `userportal`, `authen`), this project includes the following core functionalities:

* **Comprehensive E-commerce Module (`/ecom`):** Includes product catalog management, inventory tracking, and order processing workflows.
* **Dedicated User Portal (`/userportal`):** The customer-facing interface for browsing products, managing user profiles, and secure checkout.
* **Powerful Admin Dashboard (`/adminPortal`):** A secure panel for site administrators to manage users, orders, product inventory, and site content.
* **Secure Authentication (`/authen`):** Custom user registration, login, and secure session management.
* **Media Handling:** Integrated system for managing product images and user uploads.
* **Deployment Ready:** Optimized configuration files (`vercel.json`, `build.sh`) for quick deployment on platforms like Vercel.
